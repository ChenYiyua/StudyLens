# StudyLens 本地项目与测试指南

## 这个项目现在解决什么问题

StudyLens 不是把整份 PDF 扔给模型聊天，而是一条完整的学习工作流：导入课程文件夹 → 选择 Lecture 并学习 → 结合课程自带的 Exercise/Solution 讲题 → AI 生成新题检查掌握程度 → 学生作答 → AI 给形成性反馈 → MongoDB 保存历史。

## 第一次准备

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-mongodb.ps1 -Install
```

## 启动与人工测试

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run-local.ps1
```

这个命令会构建网页、启动后端并自动打开浏览器。之后使用的是普通浏览器页面，**不依赖 ChatGPT 或 Codex**。运行期间保留 PowerShell/IDE Terminal 窗口；按 `Ctrl+C` 停止。第一次运行若缺少 PDF 图片工具，脚本会自动安装 `tools/requirements.txt` 中的小型 Python 依赖。

打开 `http://127.0.0.1:5080` 后按这个顺序测试：

1. 点击 **Add files or folder**，可选多份文件，也可直接选择包含 `Lecture/Exercise/Solution` 的课程文件夹。
2. 在 **Learn the lecture** 中选择一份 Lecture，点击 Teach，确认回答按教学顺序完整收尾，并在回答下方显示最多三张真实引用页图片。
3. 在 **Understand the course exercise** 中选择一组习题，确认系统自动显示配对的 Exercise 和 Solution，然后生成讲题过程。
4. 在 **Check your understanding** 中选择检查 Lecture 或 Exercise，生成三道新题并用英文回答。
5. 查看分数、掌握点、缺失点和 improved answer；到 **Past feedback** 打开历史记录。
6. 刷新页面，确认刚才的记录仍存在——这证明它来自 MongoDB，不是 React 临时状态。
7. 打开 `http://127.0.0.1:5080/health`，确认 `storage.provider` 为 `MongoDb` 且 `available` 为 `true`。

本机 Qwen 4B 的整份 Lecture 教学通常比单句问答慢，当前电脑预计约 1–2 分钟；Gemini/GPT 云端通常更快，但需要单独的开发者 API key。模型可以先在下拉框中选择，未配置时页面会显示对应的安全配置步骤。

## 用什么软件看代码和测试

IDE 不是运行网页的必需品：PowerShell + Chrome/Edge 就能完成上面的测试。要阅读和修改代码，可以用 IDEA：

1. 在 IDEA 中选择 **File → Open**，打开整个 `StudyLens` 文件夹，不要只打开 `frontend`。
2. 选择 **View → Tool Windows → Terminal**。
3. 在 Terminal 运行 `powershell -ExecutionPolicy Bypass -File scripts\run-local.ps1`。
4. 在普通浏览器打开 `http://127.0.0.1:5080`；修改代码后停止并重新运行即可看到新版本。

IDEA 很适合查看 React/TypeScript，也能通过 Terminal 启动整个项目；但本项目后端是 C#/.NET，IntelliJ IDEA 对 C# 的代码理解和调试不如 **JetBrains Rider**。如果只装一个最省事的软件，推荐 Rider；如果想要免费且轻量，推荐 VS Code。无论选哪一个，运行与验证命令都相同。

最值得先看的三个位置：

- `frontend/dashboard/src/App.tsx`：网页和学习流程；
- `backend/StudyLens.Api/Services/TutorService.cs`：如何组织课件证据、提示词和 AI 回答；
- `tools/build_course_index.py`：如何读取并索引课程资料。

## 浏览器扩展

```powershell
cd frontend\extension
npm ci
npm run build
```

在 Chrome/Edge 的扩展管理页打开 Developer mode，选择 Load unpacked，并选中 `frontend\extension\dist`。

扩展只读取用户在当前页面明确选中的文字；不申请 cookie 或浏览历史权限。文字通过本机 URL fragment 交接，Dashboard 读取后立即清除。面试时可以把它描述为 **explicit consent + data minimization**。

## 自动验证

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify.ps1
```

当前会运行：

- 5 个 Python 索引与 PDF 图片渲染测试；
- 32 个 C# 测试（文件夹安全导入、learning path、Exercise/Solution 配对、课程 API、检索、Tutor providers、repository、固定 retrieval benchmark）；
- .NET formatting；
- Dashboard lint/build；
- Browser extension lint/build。

CI 用 fake provider 验证结构和边界，不下载数 GB 模型。真实 Ollama + MongoDB 的端到端流程需在本机验证。

## 换到另一台电脑

GitHub 能同步代码、公开 demo、测试和说明；不能同步私有课程、模型、`appsettings.Local.json`、MongoDB 学习历史或这段 Codex 对话。

新电脑上的顺序：clone → MongoDB → Ollama → 复制私有课程 → 重新 setup course → verify → run。当前电脑用 4B；RTX 3060 电脑可改为：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-local-ai.ps1 -Model "qwen3.5:9b"
```

如果另一台电脑没有当前对话，直接把它的 Codex workspace 打开在仓库根目录，并让它先读 `AGENTS.md` 和 `docs/PROJECT_HANDOFF.md`，就能从项目状态继续。
