# StudyLens 本地项目与测试指南

## 1. 在 Codex 里固定这个项目

在左侧栏找到“项目”，点击右侧的 `+`，选择添加本地项目或打开本地文件夹，然后选择：

```text
C:\Users\25330\Documents\Codex\2026-08-13\https-level3-hn-tracks-ai-engineering\StudyLens
```

一定要选择最后一级 `StudyLens`，不要选它的父文件夹。完成后，新任务会以这个 Git repository 为工作区；根目录的 `AGENTS.md` 会给 Codex 持久的项目边界和验证命令。

ChatGPT Project 主要共享聊天、上传文件和项目指令；Local Project 才直接连接电脑上的代码目录。这个项目应该使用 Local Project。

## 2. 代码在哪里

- 后端入口：`backend/StudyLens.Api/Program.cs`
- 事件 API：`backend/StudyLens.Api/Controllers/LearningEventsController.cs`
- 数据库层：`backend/StudyLens.Api/Data/`
- 后端测试：`backend/StudyLens.Api.Tests/`
- Dashboard：`frontend/dashboard/src/App.tsx`
- 浏览器扩展：`frontend/extension/src/App.tsx`
- 面试讲解：`docs/interview-notes.zh-CN.md`

## 3. 一次跑完全部检查

在项目根目录的终端运行：

```powershell
$env:RUN_MONGODB_INTEGRATION_TESTS = "true"
powershell -ExecutionPolicy Bypass -File scripts\verify.ps1
```

成功时最后会显示 `StudyLens verification passed.`。它会执行后端 10 个测试、C# 格式检查、两个前端的 lint 和 production build。

## 4. 启动可点击的 Demo

终端 1：

```powershell
$env:Storage__Provider = "MongoDb"
$env:MongoDb__ConnectionString = "mongodb://127.0.0.1:27017"
$env:MongoDb__DatabaseName = "studylens"
..\.tools\dotnet\dotnet.exe run --project backend\StudyLens.Api --urls http://127.0.0.1:5080
```

终端 2：

```powershell
Set-Location frontend\dashboard
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173`，点击 `Add demo data`。MongoDB 模式下，关闭并重新启动 API 后数据仍然存在。

## 5. 面试时怎么证明不是只会生成代码

按顺序解释：problem → privacy boundary → request flow → repository abstraction → MongoDB persistence → HTTP/integration tests → limitations。遇到不懂的类时，先从测试反推行为，再回到实现；不要死记每一行。
